# 💼 Job Application Tracker

> **Track every job application — from applied to interview to rejected, all in one place.**

Job Application Tracker is a clean, interactive web app that helps job seekers stay organized. Mark applications as Interviewed or Rejected, filter by status, delete listings, and watch your stats update in real-time — no backend needed.

🌐 **Live Site:** *https://naimxofficial.github.io/Job-Application-Tracker/*

---

## ✨ Features

| Feature | Details |
|--------|---------|
| 📊 **Live Stats Dashboard** | Real-time count of Total, Interview, and Rejected applications at the top |
| 📋 **8 Pre-loaded Job Listings** | Comes with 8 real-world style job cards across various roles and companies |
| 🟢 **Mark as Interview** | Click INTERVIEW on any card to move it to the Interview list |
| 🔴 **Mark as Rejected** | Click REJECTED on any card to move it to the Rejected list |
| 🔄 **Smart Status Switching** | Moving a job from Interview → Rejected (or vice versa) automatically updates both lists |
| 🗂️ **Filter by Status** | Switch between All, Interview, and Rejected views with one click |
| 🔢 **Dynamic Job Count** | Job count display updates based on the currently active filter |
| 🗑️ **Delete Any Job Card** | Remove any listing from any view — arrays and counters update instantly |
| 📭 **Empty State Message** | "No jobs available" placeholder shown when a filtered list is empty |
| 🏷️ **Status Badge** | Each card shows its current status — Not Applied, Interview, or Rejected |
| 📱 **Fully Responsive** | Works cleanly on mobile, tablet, and desktop |
| 🎨 **Clean UI/UX** | Minimal card-based layout with clear visual hierarchy and color-coded statuses |
